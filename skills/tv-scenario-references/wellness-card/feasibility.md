# Feasibility

- Phase: `P2`
- TV UX fit: Medium
- Live data difficulty: Medium to high
- Recommended surface: `center card` or `ambient status`
- Primary payload: `activity goal`, `sleep summary`, `stretch prompt`, `guided session launch point`
- Core dependencies: `health data source`, permission model, sensitivity handling, session launcher
- Demo scope: Show one positive metric, one lightweight prompt, and a short next action.
- Trust boundary: Keep the copy non-medical, hide sensitive metrics by default, and avoid public-screen embarrassment.
- Live blockers: Sensitive health permissions and limited value on a shared TV compared with more public scenarios.
- Korea-first notes: Use gentle, low-pressure wellness prompts that work in a shared living-room context.
