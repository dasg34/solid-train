# Feasibility

- Phase: `P0`
- TV UX fit: Very high
- Live data difficulty: Medium
- Recommended surface: `fullscreen scoreboard canvas`
- Primary payload: `live score`, `next fixture`, `standings movement`, `key moments`
- Core dependencies: `sports data feed`, refresh cadence, league schema normalization
- Demo scope: Show one hero match, secondary scores, next fixture, and a standings delta strip.
- Trust boundary: Mark stale scores clearly and avoid claiming live status when refresh is delayed.
- Live blockers: Feed freshness expectations and league-specific data normalization.
- Korea-first notes: Prioritize KBO, K League, major international football, and Korean athletes when relevant.
